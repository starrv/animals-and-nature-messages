# Animals and Nature Messages

This is an adminstrator dashboard, Animals and Nature Messages, where administrators could login and read customer feedback pertaining to Animals and Nature.  You would need an adminstrator account to view messages.  A Next.js application provides the user interface and OpenID Connect was used for authentication.  This application is deployed on Vercel.  I am using free plans for hosting so loading could take some time.  Also please note that some services could spin up and down with dynamic ip addresses used.  You could view a short demonstration via this link: [https://project-videos-vs.s3.us-east-1.amazonaws.com/animals-and-nature-messages/demo.mp4](https://project-videos-vs.s3.us-east-1.amazonaws.com/animals-and-nature-messages/demo.mp4).  Also, checkout the Animals and Nature GitHub repository for a full demonstration via this link: https://github.com/starrv/animals-and-nature.
